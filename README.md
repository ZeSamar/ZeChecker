# ZeChecker

**ZeChecker** — компактное Windows-приложение для проверки **доступности сервера по IP** и **«чистоты» IP-адреса** (прокси / VPN / датацентр / репутация) по нескольким сервисам сразу.

## Что умеет

- **Проверка доступности** IP:
  - ICMP-пинг через системный `ping.exe` (как в консоли);
  - если ICMP заблокирован — **TCP-проверка** по списку популярных портов (`22, 80, 443, 8080, 3389, 21, 3306, 25, 110, 143, 53, 8443`).
- **Проверка «чистоты» IP** по 6 сервисам:
  - ip-api.com — прокси/хостинг + провайдер;
  - proxycheck.io — прокси да/нет + тип;
  - ipwho.is — страна + организация;
  - ipinfo.io — страна + организация;
  - ip2c.org — страна;
  - ipqualityscore.com — **fraud-скор 0–100** + прокси/VPN/Tor (нужен API-ключ).
- **Вердикт**: «подозрительный (прокси/датацентр/VPN)» или «похоже на жилой IP».
- **Тёмная и светлая тема** в стиле Windows 11, своя иконка.
- **Настройки** в отдельном окне: API-ключ ipqualityscore (с маскировкой) + выбор темы.
- Лог с временем и результатом, счётчики проверок.

## Кому это надо

- **Администраторам и владельцам VPS/серверов** — быстро проверить, жив ли сервер, даже если ICMP закрыт (по TCP-порту).
- **Тем, кто проверяет «чистоту» IP** (прокси/VPN/датацентр) перед покупкой или использованием — чтобы не попасть в блокировки.
- **Пользователям VPN/прокси** — проверить, не помечен ли выходной IP как подозрительный.
- Просто **любопытным** — узнать страну, провайдера и репутацию IP по нескольким базам в одном окне.

## Использование

1. Запустите `ZeChecker.exe` (по желанию — «Запуск от имени администратора», тогда ICMP-пинг работает напрямую).
2. Введите IP-адрес в поле.
3. **«Старт»** — запустить проверку доступности (ICMP → TCP по портам).
4. **«Стоп»** — остановить проверку.
5. **«Чистота IP»** — проверить репутацию IP по 6 сервисам.
6. **«Настройки»** — вставить API-ключ ipqualityscore и выбрать тему.

## API-ключ ipqualityscore (необязательно)

Ключ нужен только для 6-го сервиса (fraud-скор). Остальные 5 работают без него.

1. Зарегистрируйтесь на [ipqualityscore.com](https://www.ipqualityscore.com) (бесплатный тариф).
2. Откройте **Dashboard → API Keys** и скопируйте ключ.
3. В приложении: **«Настройки» → поле «API-ключ ipqualityscore.com» → «Сохранить»**.

Ключ хранится локально в файле `zechecker.ini` рядом с `.exe`. Тема — в `zechecker.cfg`.

## Как это работает

- **Доступность:** приложение запускает `%SystemRoot%\System32\ping.exe -n 1 -w 1000 <ip>` и смотрит код возврата (`0` — ответ есть). Если ICMP недоступен/заблокирован, проверяется TCP-подключение к портам из списка.
- **«Чистота»:** HTTP/HTTPS-запросы к 6 сервисам, разбор ответов, сводная таблица и вердикт.

## Сборка (Windows, MinGW-w64)

```bat
windres app.rc -O coff -o app_res.o
gcc -O2 -mwindows ZeChecker.c app_res.o -o ZeChecker.exe -lws2_32 -lwininet -ldwmapi -luxtheme
```

Для иконки при желании можно перегенерировать `app.ico`:

```bat
python make_icon.py
```

## Важно

- Приложение **не является** средством обхода блокировок и не гарантирует 100% результат: «чистота» IP — это оценка по публичным базам, а доступность зависит от сети и фильтров сервера.
- Бесплатные сервисы имеют лимиты запросов; при превышении в логе будет «ошибка запроса».
- Ключ api и настройки хранятся локально в открытом виде — не публикуйте их.
